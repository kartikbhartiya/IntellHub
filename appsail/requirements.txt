# Versions are pinned to what is installable as a **Linux cp313 wheel**, because
# AppSail does not install requirements.txt server-side — the deps are vendored
# (see appsail/predeploy_check.py) and the container must be able to LOAD the
# committed .joblib artifacts rather than retrain them.
#
# That last point is the operative constraint. The registry refuses an artifact
# built by a different scikit-learn than the runtime, so a mismatch forces an
# in-process retrain of all seven models. On a 512 MB AppSail container, with the
# corpus and knowledge graph already resident, that retrain exhausts memory and
# the container thrashes. Training and serving therefore pin the same versions.
